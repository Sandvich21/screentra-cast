📡 External Monitoring

Screentra Cast exposes a lightweight unauthenticated health probe at /api/system/health. Drop the URL below into Uptime Kuma, Prometheus blackbox_exporter, Datadog HTTP check, or a plain curl loop. The endpoint is exempt from auth on purpose so external monitors can probe it without credentials. Returns: db_ok, stale_clients (count of players that haven't pinged in 5 min), server_time, version.
—
curl one-liner
—
🔧 Setup hints per monitor
Uptime Kuma: Add monitor → type HTTP(s) - Keyword → paste the URL above → accepted status code 200 → keyword "db_ok":true.
Prometheus blackbox_exporter: Add a job with probe_http_status_code == 200 as the success condition. The body is JSON; the exporter will record probe_failed_due_to_regex if you add a regex for "db_ok":true.
Datadog / New Relic HTTP check: URL above, check frequency 60s, timeout 10s. The body's stale_clients field is a useful custom metric to alert on (>0 = a player went dark).
Plain shell loop: run the curl one-liner from cron or a systemd timer. Non-zero exit on non-200. Pipe through jq .stale_clients to surface per-run player liveness counts.

🧩 Player Client Tarball

Build a downloadable tarball installer for Debian/player devices from the current player-client package. This is code/scripts/assets only (normally around 45–60 KB compressed): no layouts, cache, DB, uploads, or assignments are included. This is separate from State Bundles and Application Update Files, so client/player updates do not require a new server app version.
